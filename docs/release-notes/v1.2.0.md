# MDHub 1.2.0

An editor update to the 1.1.0 workspace. Notes are still ordinary Markdown files on your disk. There is no account, no cloud, and no proprietary format.

No .NET install is required. Each download below is a self-contained build.

On a Mac, Command stands in for Ctrl.

## New features

- **Unsaved-work recovery.** Unsaved edits, including new untitled notes, are kept in a recovery copy under app data. Original files change only when you save. The copy is written after a two-second pause in typing, after ten seconds of continuous editing, when you switch tabs or splits, when the window loses focus, and when you quit. Quitting does not ask you to save. If that copy cannot be written, the window stays open while unsaved work is still in the editor. Reopening restores the recovered documents with their text, names, original paths where they have one, and unsaved indicators. An unexpected exit brings back the last recovery copy that was written. Keystrokes made after that copy are not in the restored documents. Closing one unsaved tab still asks Save, Discard, or Cancel. Discard removes that tab’s recovery copy, and a successful save clears it. If another program changes a file you have not edited, the tab reloads from disk when it becomes active. If you have local edits, MDHub asks you to replace the disk file with those edits, reload from disk, or cancel and keep both.
- **Image viewer.** An open image can be panned, zoomed, rotated, and flipped in the viewer. The picture file on disk is left as it is. Drag with the hand tool to pan, or drag with the right button under any tool. A right click that moves less than 4 pixels still opens the menu. The wheel pans, Shift pans sideways, and Alt+wheel zooms at the pointer. Ctrl+wheel over the image zooms the image. While that image tab is showing, Ctrl+= and Ctrl+- step the zoom, and Ctrl+0 fits the image to the window. Zoom runs from 10% to 3200%. Rotate left or right by 90 degrees, or drag with the rotate tool; Shift while dragging snaps to 15 degrees. Flip horizontal or vertical from the toolbar or the image menu. The 1:1 button, and Ctrl+1 while the viewer is focused, shows actual size. With the viewer focused, H selects the hand, R selects the rotate tool, holding Space uses the hand, and Esc resets pan, zoom, rotation, and flip. The status bar shows the zoom percent and the image pixel under the pointer.
- **Insert date and time.** The formatting toolbar has an Insert Date and Time button. It inserts the local time as `yyyy-MM-dd HH:mm:ss`, replacing the selection, as one undo step. The same command is in the Edit menu and on **Ctrl+;**. The button is unavailable for a read-only or view-only document. The shortcut acts when the editor has focus.
- **Close all tabs.** Right-click a tab and choose **Close all tabs**. That closes the tabs in that split. Each unsaved tab still asks Save, Discard, or Cancel, and Cancel leaves the remaining tabs open.
- **Search untitled notes.** Folder search includes untitled notes, and those notes can be searched when no folder is open. Choosing a hit selects that tab.

## Keyboard shortcuts

- **Alt+Left** and **Alt+Right** move focus to the neighboring split and place the caret in its editor. They stop at the leftmost and rightmost split. With one split, they do nothing. On a Mac the shortcut list shows them as Option+Left and Option+Right.
- **Ctrl+Alt+Right** and **Ctrl+Alt+Left** move the active tab into the split on that side. On a Mac the keys are **Cmd+Ctrl+Right** and **Cmd+Ctrl+Left**. If there is no split on that side, MDHub opens one, up to five splits in a window. The same commands are **Move to Right Split** and **Move to Left Split** on the tab menu, and those items are shown when the move would change the layout. The only tab in the only split stays where it is. The only tab of the leftmost or rightmost split stays put when the shortcut points further outward. Moving the last tab of a split into a neighbor closes the empty split. Tab order inside a split still changes by dragging the tab.
- **Emoji picker keys.** **Ctrl+.** still opens the picker. Arrow keys move the highlight, including across category rows. Home and End jump to the first and last emoji, and Page Up and Page Down move by a page. Enter inserts the highlighted emoji and closes the picker. Escape closes it. Typing filters the search box, Down from the search box enters the grid, and Up from the top row returns to search.

## Fixes

- **Bullets nested in a numbered list.** In the preview, bullets indented under a numbered item (two or more spaces, or a tab) render as a nested list under that item. The numbered items that follow stay in the same list, with their own indentation. A bullet at the left margin stays a separate list. An intervening paragraph keeps the later bullets separate. The note’s source is unchanged, and selecting a nested bullet still maps back to that source text.

## Install

These builds are not code-signed. Windows SmartScreen and macOS Gatekeeper will warn the first time you open them. That is expected for this release.

### Windows

1. Download `Mdhub-1.2.0-win-x64.exe` and open it. There is no installer and no separate runtime to install.
2. If Microsoft Defender SmartScreen says that Windows protected your PC, choose **More info**, then **Run anyway**.

### macOS

1. Download the disk image for your Mac: `Mdhub-1.2.0-osx-arm64.dmg` on Apple silicon, or `Mdhub-1.2.0-osx-x64.dmg` on Intel.
2. Open the disk image and drag **Mdhub.app** to Applications.
3. The app is unsigned and not notarized, so Gatekeeper blocks the first open. Either:
   - Right-click **Mdhub.app**, choose **Open**, then choose **Open** again, or
   - Clear the download quarantine flag in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Mdhub.app
```

If Finder says the app is damaged, that is the same quarantine flag. The `xattr` command above clears it. You can also allow the app from System Settings > Privacy & Security.

## Known limitations

- **Not signed.** The Windows executable is not Authenticode-signed. The macOS app is not Developer ID-signed or notarized. The warnings above will keep appearing until a later release adds signing.
- **Windows, macOS Apple silicon, and macOS Intel only.** There is no Linux download in 1.2.0. You can still build from source with the .NET 10 SDK.
- **Portable Windows executable, not a setup program.** It does not add a Start menu shortcut or register a file association. The first launch extracts native libraries into a temporary folder, so it can take longer than later launches, and security software may scan those files.
- **Spell-check dictionaries are English (US), French, and Spanish.** The German dictionary is GPL and is not included; the German interface uses the English dictionary unless you pick French or Spanish. Chinese, Japanese, and Korean have interface translations but no spell-check dictionary.
- **No automatic updates.** New versions are published on this GitHub Releases page.

Third-party components (the spell-check engine, dictionaries, and file-type icons) are listed in `THIRD-PARTY-NOTICES.md` in the repository. They are included in the macOS app bundle and inside the Windows executable.
