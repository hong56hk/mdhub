# MDHub 1.0.0

First public release. MDHub is a fast, offline desktop workspace for notes stored as ordinary Markdown files on your disk. There is no account, no cloud, and no proprietary format.

No .NET install is required. Each download below is a self-contained build.

## Highlights

- **Plain Markdown files.** Notes live in normal folders. Any text editor can open them.
- **Find things quickly.** Folder explorer, tabs, Quick Open, and global search across the open folder. Search skips binary files and paths ignored by `.gitignore`.
- **A familiar editor.** Live preview, a formatting bar, find and replace, and keyboard shortcuts in the style of VS Code. Line endings (LF, CRLF, and CR) are kept as they are. Legacy encodings, including Big5 and other CJK encodings, open correctly and stay that way on save.
- **Export.** The current note can be exported to HTML or PDF.
- **Spell check** for English (US), French, and Spanish, with custom words stored locally.
- **Make it yours.** Light and dark themes, editor fonts and colors, and preview typography. An image viewer zooms with Ctrl+wheel.
- **Eight languages.** English, Traditional Chinese, Japanese, Korean, Simplified Chinese, German, French, and Spanish. The first launch follows the operating system and falls back to English.
- **Stays on your machine.** Recent folders and the tabs for each folder are restored locally. Built with .NET and Avalonia. MIT licensed.

## Install

These builds are not code-signed. Windows SmartScreen and macOS Gatekeeper will warn the first time you open them. That is expected for this release.

### Windows

1. Download `Mdhub-1.0.0-win-x64.exe` and open it. There is no installer and no separate runtime to install.
2. If Microsoft Defender SmartScreen says that Windows protected your PC, choose **More info**, then **Run anyway**.

### macOS

1. Download the disk image for your Mac: `Mdhub-1.0.0-osx-arm64.dmg` on Apple silicon, or `Mdhub-1.0.0-osx-x64.dmg` on Intel.
2. Open the disk image and drag **Mdhub.app** to Applications.
3. The app is unsigned and not notarized, so Gatekeeper blocks the first open. Either:
   - Right-click **Mdhub.app**, choose **Open**, then choose **Open** again, or
   - Clear the download quarantine flag in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Mdhub.app
```

If Finder says the app is damaged, that is the same quarantine flag. The `xattr` command above clears it. You can also allow the app from System Settings > Privacy & Security.

## Known limitations

- **Not signed.** The Windows executable is not Authenticode-signed. The macOS app is not Developer ID-signed or notarized. The warnings above will keep appearing until a later release adds signing.
- **Windows, macOS Apple silicon, and macOS Intel only.** There is no Linux download in 1.0.0. You can still build from source with the .NET 10 SDK.
- **Portable Windows executable, not a setup program.** It does not add a Start menu shortcut or register a file association. The first launch extracts native libraries into a temporary folder, so it can take longer than later launches, and security software may scan those files.
- **Spell-check dictionaries are English (US), French, and Spanish.** The German dictionary is GPL and is not included; the German interface uses the English dictionary unless you pick French or Spanish. Chinese, Japanese, and Korean have interface translations but no spell-check dictionary.
- **No automatic updates.** New versions are published on this GitHub Releases page.

Third-party components (the spell-check engine, dictionaries, and file-type icons) are listed in `THIRD-PARTY-NOTICES.md` in the repository. They are included in the macOS app bundle and inside the Windows executable.
