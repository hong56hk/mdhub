# MDHub 1.1.0

An editor update to the 1.0.0 workspace. Notes are still ordinary Markdown files on your disk. There is no account, no cloud, and no proprietary format.

No .NET install is required. Each download below is a self-contained build.

## Highlights

- **Minimap.** The editor draws a minimap to the right of the text. It is on by default. Turn it off from the editor gear with **Show minimap**.
- **View modes.** The toolbar switches among editor, split (editor and preview), and preview, with pencil, split, and eye icons. **Ctrl+M** opens the preview beside the editor, or hides it when both are already open. **Alt+M** opens the editor beside the preview, or hides the editor when both are already open. These replace **Ctrl+|** and **Alt+|**. On a Mac, Command stands in for Ctrl.
- **Split editor and caret sync.** Right-click a file in the Explorer and choose **Open to the side**, or press **Ctrl+\** (also **Ctrl+Shift+\**), to open the note in another pane. A window holds up to five panes. Views of the same note share edits, undo, and saved state. The sync button, and **Ctrl+Shift+G**, lines the editor and preview up at the caret. It is available while both panes are open.
- **Syntax highlighting.** Source files and fenced code blocks are colored by language, and inline code in Markdown gets its own color. HTML written in a Markdown file highlights tag names, attributes, quoted values, and single-line comments. **Code syntax highlighting** in the editor gear is on by default and applies immediately.
- **HTML in Markdown.** **Enable HTML formatting** is on by default. The preview renders a limited set of HTML mixed into Markdown, and the same renderer is used for `.html` files: font color, underline, superscript and subscript, alignment, lists, tables, and images with a width or height. Unsupported tags stay as source. Stylesheets and scripts are not run.
- **Column editing.** Hold **Shift+Alt** and press **Up** or **Down** to add a caret on the line above or below. Typing, navigation, and **Shift** selections apply at every caret. **Esc** returns to one caret.
- **Toolbar icons.** Undo, redo, insert link, export to HTML, the emoji button, and the view-mode controls are drawn icons. A separator sits between the view modes and Export HTML, and another between Export PDF and Editor Settings.

## Editing

- The formatting buttons apply to the selected text, including bold, italic, strike, code, headings, lists, quote, and link. The font color button opens a picker of swatches and a `#RRGGBB` field, then colors the selection. With nothing selected, the buttons keep their previous behavior.
- **Ctrl+U** converts the selection to uppercase and **Ctrl+Shift+U** converts it to lowercase. Both can be changed in the shortcut dialog, and a new binding takes effect immediately.
- **Ctrl+Shift+V** pastes clipboard text only. It replaces the selection, normalizes line endings to the note, and does not turn a clipboard image into a saved asset.
- The emoji button, and **Ctrl+.**, opens a picker with search, categories, and recent emoji. The character is inserted as ordinary text. Shortcodes such as `:smile:` stay literal.

## Navigation & layout

- The document outline lists the headings in a Markdown note. It is off until you open it from the toolbar, and it stays hidden for files that are not Markdown.
- The editor and the preview keep about a screen of empty space below the last line, so that line can scroll to the top. Resizing adjusts the space. It is not written into the file.
- The preview’s vertical scrollbar stays expanded instead of shrinking when idle.
- Drag a tab left or right to change its order. The dragged tab stays active.
- **Ctrl+T** opens a new empty tab, the same as **Ctrl+N**. **Ctrl+Shift+T** reopens the most recently closed tab, and further presses restore earlier ones. A closed file is read from disk again and returns to its previous tab position.
- Drop files from outside the workspace onto the Explorer to copy them into the folder you drop them on.
- The Explorer menu includes **Remove unused images** and **Remove unused images recursively**. Each command looks in that folder’s `.assets` directory and compares the images with the Markdown files beside it. The recursive command repeats this in subfolders. A confirmation lists the count and the relative paths. Confirming moves the files to the Recycle Bin. Cancelling leaves them in place.

## Docs

- **Help → Markdown Guide** now includes rendered examples and the matching source for font colors, HTML formatting, superscript and subscript, sized images, emoji, alignment, tables, lists, and special characters.

## Install

These builds are not code-signed. Windows SmartScreen and macOS Gatekeeper will warn the first time you open them. That is expected for this release.

### Windows

1. Download `Mdhub-1.1.0-win-x64.exe` and open it. There is no installer and no separate runtime to install.
2. If Microsoft Defender SmartScreen says that Windows protected your PC, choose **More info**, then **Run anyway**.

### macOS

1. Download the disk image for your Mac: `Mdhub-1.1.0-osx-arm64.dmg` on Apple silicon, or `Mdhub-1.1.0-osx-x64.dmg` on Intel.
2. Open the disk image and drag **Mdhub.app** to Applications.
3. The app is unsigned and not notarized, so Gatekeeper blocks the first open. Either:
   - Right-click **Mdhub.app**, choose **Open**, then choose **Open** again, or
   - Clear the download quarantine flag in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Mdhub.app
```

If Finder says the app is damaged, that is the same quarantine flag. The `xattr` command above clears it. You can also allow the app from System Settings > Privacy & Security.

## Known limitations

- **Not signed.** The Windows executable is not Authenticode-signed. The macOS app is not Developer ID-signed or notarized. The warnings above will keep appearing until a later release adds signing.
- **Windows, macOS Apple silicon, and macOS Intel only.** There is no Linux download in 1.1.0. You can still build from source with the .NET 10 SDK.
- **Portable Windows executable, not a setup program.** It does not add a Start menu shortcut or register a file association. The first launch extracts native libraries into a temporary folder, so it can take longer than later launches, and security software may scan those files.
- **Spell-check dictionaries are English (US), French, and Spanish.** The German dictionary is GPL and is not included; the German interface uses the English dictionary unless you pick French or Spanish. Chinese, Japanese, and Korean have interface translations but no spell-check dictionary.
- **No automatic updates.** New versions are published on this GitHub Releases page.

Third-party components (the spell-check engine, dictionaries, and file-type icons) are listed in `THIRD-PARTY-NOTICES.md` in the repository. They are included in the macOS app bundle and inside the Windows executable.
